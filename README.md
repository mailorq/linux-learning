# linux learning

Интерактивный тренажер для практики администрирования Debian и Ubuntu. Он разбирает введенные команды, проверяет их смысл и объясняет ошибки.

## Что можно тренировать

В сценариях есть управление пакетами и службами, чтение журналов, диагностика сети и диска, настройка прав, архивирование и базовые команды докер. Сложность задания указана в yaml файлах. Во время прохождения доступны три уровня подсказок: концепция, нужные инструменты и пример решения.

Проверка учитывает короткие и длинные флаги, их порядок, позиционные аргументы, пайпы и перенаправления. После команды тренажер показывает разбор использованных флагов, а в конце сессии выводит статистику. История ввода и прогресс сохраняются локально.

## Требования

- Python 3.14
- Пакетный менеджер UV

## Установка

Из корня выполните:

```text
uv sync --extra dev
```

Команда создаст виртуальное окружение, установит зависимости и инструменты проверки из lock-файла.

## Запуск

```text
uv run linux-learning
```

Можно отобрать задания по уровню или теме.

```text
uv run linux-learning --level beginner
uv run linux-learning --topic network
uv run linux-learning --level intermediate --topic services
```

В интерактивном режиме команда `:hint` открывает следующую подсказку, `:skip` пропускает задание, `:help` показывает команды тренажера, а `:quit` завершает сессию. Подсказки повышают штраф прогресса.

По умолчанию история ввода хранится в `~/.linux-learning/history`, а прогресс в `~/.linux-learning/progress.sqlite3`.

## Сценарии

Рабочие yaml сценарии находятся в `scenarios`. Чтобы добавить задание, создайте там файл `.yaml` с уникальным `id`, уровнем, темой, задачей, правилами команд, тремя подсказками и объяснением успешного решения. Структуру можно сверить с существующими сценариями.

## Черновики из tldr

Генератор читает уже имеющиеся локально markdown-страницы tldr для линукс. Сгенерированные файлы являются черновиками: перед добавлением в `scenarios` проверьте формулировку задания, правила команды и подсказки.

```text
uv run python -m linux_learning.scenario_generator путь/к/tldr/pages/linux --output-dir scenario-drafts
```

По умолчанию рассматриваются страницы `apt`, `systemctl`, `journalctl`, `ip`, `ss`, `ufw`, `chmod`, `chown`, `tar`, `grep`, `sed`, `awk` и `docker`. Существующие черновики не перезаписываются. Для явной перезаписи укажите `--overwrite`.
