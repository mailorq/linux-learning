## Основные Части Приложения

`models.py` описывает сценарий, подсказки и правила команды. pydantic проверяет yaml при загрузке, запрещает неизвестные поля и сообщает о неверной структуре до начала сессии

`scenario_loader.py` читает локальные yaml файлы. загрузка отделена от моделей, чтобы ошибки чтения файлов не смешивались с ошибками их содержимого

`command_parser.py` разбирает поддерживаемую часть shell синтаксиса: кавычки, флаги, пайпы и перенаправления. shlex помогает сохранить аргументы в кавычках, небольшой собственный разбор выделяет операторы. команды не передаются оболочке на выполнение

`validator.py` проверяет разобранную команду по правилам сценария: утилиту, флаги, аргументы, пайп и перенаправления. `feedback.py` превращает найденные расхождения в объяснение для пользователя

`cli.py` связывает сценарии, ввод, подсказки, обратную связь и статистику. rich отвечает за вывод, prompt-toolkit за историю и дополнение команд

`progress.py` хранит результаты в sqlite через sqlalchemy. база остается одним локальным файлом, без отдельного сервера; sqlalchemy описывает таблицы, связь ошибок с сессиями и ограничения целостности

`scenario_generator.py` создает черновики из локальных markdown страниц tldr. черновик сохраняет источник и требует редакторской проверки, поэтому генератор не добавляет задания прямо в рабочий набор

`errors.py` содержит ошибки, которые обрабатываются на границах загрузки сценариев, разбора команд и работы с прогрессом
